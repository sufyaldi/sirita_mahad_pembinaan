Tentang Modul

Modul sirita_mahad_pembinaan merupakan ekstensi komprehensif Odoo untuk menstandardisasi tata kelola kurikulum kepesantrenan, pengawasan perizinan mahasantri, serta penegakan kedisiplinan di lingkungan Ma'had Al-Jami'ah Perguruan Tinggi Keagamaan Islam Negeri (PTKIN). Modul ini bekerja berdampingan dengan manajemen hunian asrama guna mewujudkan ekosistem pembinaan karakter, spiritualitas, dan akademik mahasantri yang transparan, modern, dan akuntabel.

Fitur Utama & Keunggulan

Dirancang khusus menjawab kebutuhan operasional Ma'had Al-Jami'ah PTKIN

📚

Halaqah Ta'lim & Buku Kendali Hafalan

Pengelompokan santri ke dalam halaqah Al-Qur'an dan Kitab Kuning per semester/tahun akademik. Dilengkapi pencatatan setoran hafalan Ziyadah dan Muraja'ah (Surah, rentang ayat, tajwid, status mutqin, serta validasi musyrif).

🎓

Syahadah Kelulusan & API SIAKAD

Penerbitan ijazah/sertifikat Syahadah Ma'had resmi dengan pengesahan berjenjang hingga Mudir. Terintegrasi REST API /api/mahad/syahadah/status untuk validasi syarat ujian skripsi/munaqasyah mahasiswa di SIAKAD kampus.

🔎

Izin Pesiar & Bermalam via QR Gate

Pengajuan izin keluar asrama maupun bermalam/pulang kampung dengan approval Musyrif. Dilengkapi QR Code token unik dan endpoint REST API pos satpam /api/mahad/permit/scan_qr serta auto-cron deteksi keterlambatan santri.

⚖

Kedisiplinan & Takzir Edukatif

Katalog bobot poin pelanggaran (Ringan, Sedang, Berat) dengan kalkulasi otomatis Surat Peringatan (SP-1, SP-2, SP-3). Sistem sanksi berfokus pada Takzir Edukatif pembinaan karakter spiritual tanpa kekerasan fisik.

💳

Wizard Penagihan Massal Asrama BLU

Kemudahan generate tagihan/invoice biaya hunian santri secara massal terfilter menurut gedung, lantai, kamar, atau angkatan santri yang siap terhubung dengan modul invoice keuangan lembaga/BLU.

Hierarki Hak Akses Pengguna

Peran (Role) Kewenangan & Tanggung Jawab Operasional
Musyrif / User Input buku kendali hafalan santri binaan, absensi ta'lim, approval izin harian/pesiar, dan input temuan pelanggaran awal.
Pengelola / Manager Manajemen master halaqah, penetapan musyrif pengampu, konfirmasi perizinan bermalam, verifikasi takzir edukatif, dan eksekusi wizard penagihan massal.
Mudir / Admin Pengesahan final Syahadah Ma'had, otorisasi penerbitan Surat Peringatan (SP), konfigurasi aturan tata tertib dan integrasi webhook/API.
